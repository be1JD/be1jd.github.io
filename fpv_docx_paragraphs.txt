67: Step 1. Remove Cover
68: Remove the four screws from the bottom of the RC car keeping the top plastic cover in place, and put the screws aside for later reassembly.
69: Remove the top cover. You will be exposed to the Inner electronics of the car as shown in the image.
70: Step 2. Remove the Electronics
71: Remove all the electronics except for the power switch and the rear motor. 
72: After trying multiple toy RC cars I found that most steering motors consumed too much power and were difficult to control precisely. That's why I replaced it with a servo for more control and power efficiency.
73: After removing the steering motor place servo motor such that its rotating shaft center matches the wheels rotating gear center. 
74: Fix the servo in place with two side taps or adhesive. We will check the servo using the Web Controller later on.
75: Step 3. Making Main PCB Board
76: I am making a Modular PCB but you can connect these things directly with esp32 if you want to. Just that the modular PCB is more convenient.
77: Cut General PCB Board such that it can easily be fitted on the Car body. Once you cut the appropriate part then start placing the components & connectors as per the Block diagram of Main PCB.

80: { Servo Motor Pinout }
81: Overall Connectors and their purpose : 
82: - 3 Male Header Pins for Servo Motor
83: - 4 Male Header Pins for Rear Motor
84: - 1 Screw Terminal for 5v Power input 
85: - 1 Screw Terminal for Direct Battery Power Input
86: - 1 Screw Terminal for Powering Motor
87: - 1 JST connector for Powering Motor Driver
88: - 2 Header Pins for Powering ESP32-CAM
89: - 1 Power Switch
90: { ESP32 Pinout }
91: ESP Pinouts for Reference
92: Pin 26  :- Servo Motor PWM Pin
93: Pin 19  :-  Q1 : BD140 (PNP) transistor for backward direction 
94: Pin 18  :-  Q2 : BD140 (PNP) transistor for forward direction 
95: Pin 5    :-  Q3 : BD139 (NPN) transistor for forward direction 
96: Pin 21  :-  Q4 : BD139 (NPN) transistor for backward direction
97: Pin 34 :- Battery Voltage Monitoring If you want to add it.
98: Steps : 
99: First Solder Two parallel 40 pin Female Header for ESP32 & then Place ESP32 for correct pin referencing of other components.
100: Place the 3 Male Header Pins for Servo motor on PCB such that Servo’s PWM pin   aligns with ESP32 Steer Out Pin ( GPIO 26 ). Solder Header Pin in place.
101: Now take 4 Male Header pins for Rear Motor control and place them parallely to the GPIO 19, 18, 5 & 21. Also solder them in place.
102: Now Solder all three Screw Terminals as shown in image for 5v Input, Battery input & Motor Driver Power. you can place them as per your convenience. 
103: Also Solder JST Connector or Header Pin for Powering ESP CAM & If you’re not using it then you can skip this step.
104: You can Place Switch on the PCB or Extend it through Wire up to your choice. I have used it between the Charging Module Output & Volt booster.
105: Now Take Single Strand Wires and connect components with the Help of Circuit Diagram. 
106: {  Main PCB Layout}
107: After soldering Connect Battery and Check if the ESP 32 is powering up. 
108: Step 4. Making Custom Motor Driver
109: { Picture of Motor Driver }
110: 	If you are using a ready made Motor Driver module You can Ignore this step and directly connect the motor driver using the pinout diagram shown above.
111: { Main Motor Driver Block Diagram }
112: { Main Motor Driver Circuit Diagram }
113: { BD139 & BD140 Pinout }
114:         	Take a small PCB & Place two BD139 NPN transistors and two BD140 PNP transistors & Solder Them on PCB as shown in the reference Image. Both BD139 and BD140 have the same Pinouts. Correct Pin Polarity is Important. 
115: Once you are confident about Transistor Placement, Solder them in place and interconnect them according to the Circuit Diagram. You can Use Screw Terminals for Connecting Motor if You want. 
116: { Current Amplifier Circuit Diagram }
117: { BC547 & BC557 Pinout }
118: 	Now take another small piece of small PCB & Place the BC547 & BC557 Transistors by following the Circuit Diagram. Also the Pinout for BC547 & BC557 are the same. Once Placing the Transistors Place Its time to Place resistors. 
119: Put the 33 ohm resistor in series with all the pins going from the current Amplifier to the Main Motor Driver and Put 1k ohm resistor in series with all the pins that are coming from esp32 to motor driver. 
120: It's important to place correct value resistors otherwise your esp32 or other components may damage so double check the values and connections.

126: Step 6. Setting Up the Software
127: Install Arduino IDE if you don't have it already. 
128: { ESP32 Connected to PC }
129: Connect ESP32 Dev Board with the PC using Micro USB cable.
130: { Image 1x Installing Board Supports }
131: Add ESP32 Board in ESP32 by going into 
132: File -> Preferences -> Additional Board Manager URLs Paste following URL here : “https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json” 
133: Then Click "Ok".
134: { Image 2x Installing Board Supports }
135: Now Add Board support Tools -> Board -> Boards Manager, Search for esp32 and install esp32 by Espressif Systems & Install It.
136: { Image 3x Installing Drivers }
137: Search for CP210x driver install on google and Install CP210x VCP Windows Driver from the silicon labs website. 
138: https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers?tab=downloads
139: If this Driver doesn't Work your board may have different chips so Install CP340 Driver. 
140: https://sparks.gogo.co.nz/ch340.html?srsltid=AfmBOoqFrgVHV3i_JpFbHGfBbBkL_CMcwzBjEJOwl8L5Ie6VV0qmCTNt
141: 	Download Zip file -> Extract file -> Run Setup -> Install it.
