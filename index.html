    About Me

    Embedded systems and web-connected hardware.

    I'm JD Patel, a Gujarat-based maker focused on embedded electronics and the web interfaces that control them. My work centers on microcontroller firmware (ESP32/Arduino), wireless control over Wi-Fi and WebSockets, and the browser-based dashboards that turn a circuit board into something anyone can drive.

    This site is both a portfolio and a build log: every project ships with working firmware, a step-by-step guide, and a live demo, so the process is as visible as the result.

    What I build with

    Embedded & Hardware

    ESP32 / Arduino firmware, sensor integration, motor and servo control, circuit prototyping.

    Wireless & Networking

    Wi-Fi access points, real-time WebSocket control, async web servers on microcontrollers.

    Web & Interfaces

    HTML, CSS, and JavaScript front ends built to control hardware directly from a browser, no app required.

    Documentation

    Build guides, wiring references, and firmware notes written so someone else can reproduce the project end to end.
